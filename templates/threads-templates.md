# Threads 貼文模板庫

所有內容 skill 產草稿時從這裡選模板與 hook。規則見 `docs/content-strategy.md`
（重點：單則 ≤500 字元、連結一律放回覆串、結尾必有低門檻提問、每則 1 個主題標籤）。

## Hook 句庫（第一行決定生死）

**數字反差型**（適合工具雷達）
- 「這週 GitHub 上竄最快的 N 個工具，第 X 個直接幫你省訂閱費 👇」
- 「一個月前還是 0 星，現在 N 萬星：這 N 個專案發生了什麼」
- 「N 個工具，全部免費，全部這週才紅起來」

**立場衝突型**（適合短評，最容易收回覆）
- 「大家都在吹 X，我實測完想說點不一樣的」
- 「X 這個新工具，我的結論：先別裝」
- 「這件事中文圈還沒人講：…」

**親測背書型**（適合實測報告）
- 「我把 X 裝起來用了三天，講三個真心話」
- 「花了一個晚上實測 X，幫你踩完雷了」

**利益直給型**（通用）
- 「如果你也覺得 AI 工具訂閱費太貴，這篇幫你省下來」
- 「N 分鐘設定好，之後每天自動幫你 X」

**SaaS 平替型**（省錢線主力）
- 「這個免費 repo，取代了我每月 $XX 的 {SaaS 名}」
- 「{SaaS 名} 一年收你 $XXX，開源社群做了個免費的」
- 「還在付 {SaaS 名} 訂閱費的人，先看完這篇再續約」

**習慣養成型**（適合週報）
- 「本週 AI 圈五件事，一分鐘看完 ☕」
- 「這週你可能錯過的：…」

## 模板 A：工具雷達（github-trending）

```
{hook}

{emoji} {名字}：{一句話用途}。{成長數據}，{免費/要key}
{emoji} {名字}：{一句話用途}…
{emoji} {名字}：{一句話用途}…

---（回覆串 2）---
{其餘 2–3 個工具}

全部連結放留言。{低門檻提問}

#{主題標籤}

---（回覆串 3：連結）---
{名字}: {短連結}
…
```

## 模板 B：今日短評（ai-news）

```
{hook：對單一事件的立場}

{事件一句話} + {為什麼重要（對讀者的實際影響）}

我的看法：{具體立場，敢下結論}

{低門檻提問，例：你們會因為這個換工具嗎？}

#{主題標籤}

---（回覆串 2：連結與補充）---
來源：{連結}
{次要事件 1–2 條，各一句話}
```

## 模板 C：實測報告（tool-deep-dive）

```
{hook：親測背書型}

測了什麼：{工具名} —— {一句話用途}

👍 {真的好用的點，具體}
👎 {踩到的雷，具體}
💰 {費用真相：免費額度夠不夠用}

結論：{值得裝 / 先觀望 / 等 X 功能再說}

{低門檻提問}

#{主題標籤}

---（回覆串 2）---
安裝指令與完整筆記：
{指令}
{repo 連結}
```

## 模板 E：SaaS 平替（省錢線）

```
{hook：SaaS 平替型}

它取代誰：{SaaS 名}（${X}/月）
它是什麼：{repo 名} —— {一句話}

💸 省下：${X}/月
🧾 真實成本：{安裝時間} + {主機需求或 $Y/月 VPS}
{✅ 走官方 API / ⚠️ 非官方自動化，有停權風險}

適合誰：{一句話}；不適合：{一句話}

{低門檻提問，例：你每月訂閱費最想砍哪一筆？}

#{主題標籤}

---（回覆串 2：安裝指令與連結）---
```

## 模板 D：週報（weekly-digest）

```
{hook：習慣養成型}

1️⃣ {本週最大事件一句話}
2️⃣ {次要事件}
3️⃣ {本帳號本週最受歡迎的工具回顧}

下週我會實測 {預告}，想看什麼優先測？留言告訴我

#{主題標籤}

---（回覆串 2：本週完整清單與連結）---
```

## 檢查清單（發布前逐項過）

- [ ] 第一行拿掉會不會讓人划走？會 → 重寫 hook
- [ ] 主文有沒有夾任何 http 連結？有 → 移到回覆串
- [ ] 每則都 ≤500 字元？
- [ ] 結尾有低門檻提問？
- [ ] 數字都有出處？「實測」的部分真的測過？
- [ ] 有沒有「炸裂／顛覆／全網」等禁用詞？
