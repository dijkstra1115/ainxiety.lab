# 長期經營策略：從內容工廠到信任品牌

> 與 ROADMAP.md 的分工：ROADMAP 管「產線技術」怎麼升級，本文管「帳號生意」怎麼長大。
> 所有階段用**里程碑觸發**而非日期——達標才進下一階，沒達標就留在原地迭代。

## 核心論點

工具介紹是門檻極低的內容類型（人人都能翻譯 README），所以長期價值不在「資訊」
而在「信任」：讀者最終追蹤的是「這個帳號說值得裝，我就敢裝」。
我們有三個累積型資產，別人短期抄不走：

1. **實測資料庫**：每篇 deep-dive 的安裝時間、體積、踩雷紀錄都存在 repo——
   兩年後這是中文圈最大的開源工具實測語料
2. **公開戰績**：我們推薦時的星數都記錄在 seen.json——「我們在它 5k 星時就說會爆，
   現在 40k」是可驗證的眼光證明
3. **內容工廠本身**：這個帳號由 AI 產線經營、repo 全程公開——
   「我怎麼用 Claude 自動經營自媒體」本身就是最有話題性的內容與最終的產品

## 階段一：存活與校準（現在 → 穩定週更 8 週）

**目標**：不斷更，找出哪條內容線有共鳴。
- 照策略文件跑：週 3 則起步、metrics.json 回填、weekly-digest 分析
- **開啟「戰績」機制**：每期雷達記錄推薦時星數（已自動），每月發一篇
  「上月雷達回顧：我們推的 N 個，現在長怎樣」——對了大方講，錯了也大方講，
  「打臉自己」的貼文反而是信任加速器
- 先不碰任何變現，一次贊助合作都不接

**進下一階的條件**：連續 8 週不斷更，且找出互動率明顯領先的內容線。

## 階段二：差異化定樁（約 3–6 個月）

**目標**：從「又一個工具帳號」變成「那個真的會測、講清楚錢的帳號」。

- **加開後設內容線（build in public）**：公開「這個帳號是 AI 內容工廠跑的」，
  不定期發產線幕後——「今天 Claude 自動挖到這個工具、自動產了這張圖」。
  誠實揭露反而是流量點：中文圈在做這件事的人極少，而 repo 公開就是可驗證的證明。
  這條線同時預熱階段四的產品
- **Dogfooding 迴圈**：把我們推薦過的最好工具用進自己的產線
  （例：用 video-use 剪自己的短影片、用 openreply 管自己的留言），
  「我自己每天在用」是最強的推薦語，使用心得又回頭變成內容
- **GitHub Pages 免費站**：reports/ 的 markdown 自動變靜態網站（零成本），
  吃搜尋長尾（「XXX 教學」「XXX 替代品」），Threads 之外多一條被動流量
- IG 同步：配圖卡本來就是 1080×1350，直接當 IG 圖文發，成本近零

**進下一階的條件**：出現穩定的「讀者點播」（留言指定要測什麼）——代表信任成形。

## 階段三：受眾資產化（約 6–12 個月）

**目標**：把演算法借來的流量，換成自己擁有的名單。

- **電子報**（Substack/Ghost 免費層）：weekly-digest 直接改寫，Threads 每週導流一次。
  電子報名單是唯一不會被演算法沒收的資產，這步不能省
- **社群**：讀者夠活躍後開 Discord/LINE 社群（「自架互助會」定位——
  大家一起踩雷一起省訂閱費），社群提問直接變成實測選題，內容飛輪閉環
- 影音試水：用 video-use 把實測報告剪成短影片（工具本身就是我們推薦過的——
  後設又成立一次）。Reels/Shorts 是現階段觸及紅利最高的形式

**進下一階的條件**：電子報 ≥1,000 訂閱或單月穩定 50+ 名單成長。

## 階段四：變現階梯（信任足夠之後才開始）

由輕到重，**永遠先賣自己的東西，再考慮別人的錢**：

1. **知識產品**：「用 Claude 打造你自己的內容工廠」——這個 repo 就是課程/模板的
   現成教材，目標客群正是想做自媒體但沒時間的人。低邊際成本，與人設零衝突
2. **付費電子報深度版**：免費版給結論，付費版給完整實測數據＋每月一對一選題投票
3. **服務型收入**：幫小商家/創作者代架 SaaS 平替（openreply、kaneo 這類）——
   台灣中小企業市場對「一次費用取代月租」接受度高，客單價可觀；
   做十單就能寫成「代架服務標準流程」再產品化
4. **贊助與聯盟（最後開、規則最嚴）**：「不吹捧」是帳號命脈，所以——
   接贊助必須大字標註「合作」；聯盟連結只放「自己真的在用」的工具；
   任何工具的負評權保留（合約先講清楚，不接受審稿）。
   一次違規性的軟廣就能燒掉兩年信任，寧可不賺

## 風險清單（每季回顧一次）

| 風險 | 對策 |
|---|---|
| Threads 演算法轉向/衰退 | 階段三的電子報與 SEO 站是保險；配圖卡多平台複用 |
| AI 生成內容氾濫、清單文貶值 | 護城河在實測數據與戰績，不在清單本身；加重 deep-dive 佔比 |
| 被抄襲（內容連格式一起抄） | 抄得走格式抄不走 repo 歷史與戰績；必要時公開對比 |
| 推薦的工具出事（資安/跑路） | 誠實守則已要求標註風險；出事第一時間發更正——處理得好反而加分 |
| 個人時間耗盡 | 產線已自動化 80%；人工只保留選題否決權與最後把關 |
| 單一 AI 供應商依賴（產線靠 Claude） | repo 全是開放格式（md/py），skill 邏輯可遷移；成本納入月度檢視 |

## 一頁總結

```
現在：穩定出貨 + 記錄戰績（信任的原料）
3-6 月：build in public + dogfooding + 免費 SEO 站（差異化）
6-12 月：電子報 + 社群 + 短影片（把流量變資產）
12 月後：知識產品 → 付費深度版 → 代架服務 → 嚴格條件下的贊助（變現）
不變的鐵律：不吹捧、算完整的帳、錯了公開認——信任是唯一的複利
```
