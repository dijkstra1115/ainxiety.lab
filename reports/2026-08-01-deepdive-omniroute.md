# 實測報告：OmniRoute（diegosouzapw/OmniRoute）2026-08-01

> 環境:Linux 沙盒（無對外網路連線）、Node/npm、時間盒 30 分鐘。
> 網路限制影響:無法實測上游免費模型的真實回應品質——此部分明確標註「未測」。

## 實測筆記

### 安裝（真實計時）

```bash
npm install omniroute        # 實測：2 分 53 秒
```

- ⚠️ **安裝體積 3.3 GB**。README 沒有提醒這件事，磁碟小的機器（例如雲端開發環境）會很痛
- 安裝過程無需任何設定、無需註冊、無需 API key——這點官方沒有騙人

### 啟動

```bash
omniroute                    # 實測：9.3 秒啟動完成，v3.8.49
```

- 首次啟動自動產生加密金鑰（`~/.omniroute/.env`），零設定即起
- 儀表板 `http://localhost:20128`（自動導向 `/dashboard`），API base `http://localhost:20128/v1`
- **記憶體佔用實測約 570–685 MB**——比一般 CLI 工具重不少，它本質上是一個完整的本地 gateway 服務

### API 行為實測

```bash
curl http://localhost:20128/v1/models
```
- ✅ 標準 OpenAI 相容格式。開箱即有 `auto/best-coding`、`auto/best-reasoning` 等聚合模型，
  聲稱 context 1M tokens（這是聚合上限宣告，實際依當下路由到的上游而定）

```bash
curl -X POST .../v1/chat/completions -d '{"model":"auto", ...}'
```
- 因沙盒無對外網路，上游呼叫必然失敗——但失敗回應反而展示了它的核心機制：
  診斷資訊完整列出**免費供應商池（poolSize: 11）**、嘗試順序（opencode → felo-web →重試）、
  排除原因、以及具體的 recovery 建議。錯誤處理是認真做的
- ❗ 未測：免費上游模型的實際回應品質、延遲、額度耗盡的切換體驗（需有網路環境）

## 結論

- 👍 **零設定是真的**：裝完即起，11 家免費供應商已預接好，不用註冊任何帳號
- 👍 **工程品質好**：OpenAI 相容 API 乾淨、錯誤診斷詳細到罕見（附嘗試鏈與恢復建議）
- 👎 **資源大戶**：3.3 GB 磁碟 + 600 MB 上下記憶體，「輕量工具」的期待請先調整
- 💰 **費用真相**：工具本身 MIT 免費、零遙測；免費模型池是「別人家的免費額度」的聚合，
  品質與穩定性未測，重要工作流建議仍綁自己的付費 key 當備援
- 🎯 **一句話**：值得裝——如果你有 4 GB 磁碟可捐，而且想省 AI 訂閱費；
  追求輕量的人先觀望
